# WRAITER 0.11.0 — Project-aware writing and proofreading

WRAITER 0.11.0 adds selective proofreading, richer manuscript statistics, saved assistant conversations, and safer work across several open projects. This release includes the 0.10 proofreading work, which was not published as a separate GitHub release.

## Download and start

- **WRAITER-0.11.0-Setup.exe** — recommended. Guided per-user installation with a choice of folder and Windows shortcuts.
- **WRAITER-0.11.0-Windows.exe** — portable application. Runs without installation; settings and recovery data still use your Windows user profile.
- **WRAITER-0.11.0-SHA256SUMS.txt** — SHA-256 checksums for both executables.

Choose an `.exe` under **Assets**, rather than GitHub's Source code archives. This release targets Windows 10/11 on x64 Intel/AMD computers. The executables are unsigned, so Windows may show an unknown-publisher or reputation warning.

## What is new

- **Selective proofreading.** Review selected text, one chapter, or the whole manuscript. Findings are grouped by severity and category with explanations and before/after text. Edit, select, and apply only the fixes you want; each applied batch is one persistent undo step.
- **Statistics and spelling controls.** Inspect practical and editorial manuscript statistics, estimated reading time, vocabulary figures, chapter comparisons, and a configurable page estimate. Chromium's local spelling underlines remain separate from AI proofreading.
- **Saved project conversations.** Assistant chats now stay with their project and can be reopened from the chat selector. Start a new conversation without losing earlier sessions.
- **Background project assistance.** A chat can finish against its originating project while you work in another tab. WRAITER shows working/reply indicators and applies completed edits when you return. Untouched chapters can keep changing while a request runs; changed targets are rejected instead of overwritten.
- **Safer external reloads.** When another program changes an open document, load the disk version while preserving the current draft in Open Recent and starting a fresh undo history.
- **Optional margin numbering.** Independently enable row, page, and paragraph numbers without adding them to manuscript text, exports, or editing history.
- **A clearer GitHub introduction.** The README now demonstrates inline continuation, selected-text rephrasing, project-aware assistance, proofreading, and the in-app tutorial with focused dark-mode screenshots.

## Privacy and present limits

Manuscripts, recovery data, and assistant chats remain on your computer. Chats are excluded from manuscript exports. Requested cloud AI tasks send the needed text and enabled context to the selected provider; private notes remain excluded. Local AI can work offline after its engine and model are installed.

This remains an early preview. Keep separate backups of important writing and review AI suggestions before applying them. A complete fresh-PC installation and live Claude Code inference still need wider validation. macOS, Linux, and Windows on ARM builds are not provided.
