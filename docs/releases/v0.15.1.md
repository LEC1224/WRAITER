# WRAITER 0.15.1 — Right-click editing actions

This local Windows build adds formatting, comments and AI actions to the manuscript's native right-click menu. It includes the search, comments and toolbar formatting tools from 0.15.0. It has not been published as a GitHub release.

## Changes

- **Copy formatting**, **Paste formatting**, **Clear formatting** and **Add comment…** act on the selected passage. Formatting paste preserves the target words, links and comment anchors and remains one undo step.
- Selected text offers **Rephrase / translate selection** and **Correct spelling and grammar**. A cursor offers **Continue writing here**. These use the configured task models and keep results as previews until accepted.
- **Ask assistant about selection…** opens and focuses the question composer with the passage retained. Opening the composer sends no request.
- **Accept suggestion**, **Dismiss suggestion**, **Stop generating**, **Enable AI** and **AI settings…** are available when applicable. Disabled actions reflect the selection, formatting buffer and current request.
- A right-click within a selection preserves it; a right-click elsewhere moves the cursor. **Shift+F10** supports keyboard access. Undo/Redo use WRAITER's persistent history. Existing spelling suggestions and ordinary text-field menus are preserved.
- Right-clicking commented text no longer opens the comment sidebar. Menu callbacks reject passages that changed while the menu was open.
