# WRAITER 0.20.5

Local Windows preview, 10 November 2026.

English live grammar now combines broader compact-model checks with a bundled
neural grammar model. It catches more agreement, verb-form, pronoun-case, and
word-choice mistakes from sentence context. It runs entirely on the CPU without
an account, model download, network connection, or cloud allowance, including
when the optional generative AI tools are disabled.

The new neural layer leaves quoted dialogue to the established checks and
filters broad word rewrites and uncertain suggestions. Recognizable informal
quoted verb forms and the optional less/fewer distinction are left to the
writer. Suggestions still require a user action to change the manuscript and
remain undoable.

Noun corrections now handle known irregular and ambiguous inflections without
inventing singular spellings. Closing WRAITER also lets active grammar inference
finish and release its resources after saving, avoiding unsafe termination of
the native model worker.

On a fresh frozen set of 120 synthetic passages, the packaged application
marked 40 of 60 labeled grammar issues, up from 32 in the preceding compact-model
build. Unsupported underlines fell from five to four. On the known original
48-passage race it marked 16 of 21 issues with no unsupported underlines;
the saved Google Docs result was 17 of 21 with none. The race and earlier Terra
sets were used during development, so they do not establish independent parity
with Google Docs. These are detection scores; overlapping an issue does not
prove the suggested replacement is right.

The model and runtime increase installer size and local memory use. Inference
runs in a shared background worker with two CPU threads, bounded work, and
automatic unloading when idle. See [offline grammar](../OFFLINE-GRAMMAR.md) and
the [model evaluation notes](../../tools/grammar-model/README.md) for coverage,
reproducibility, licensing, and limitations.
