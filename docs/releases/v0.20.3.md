# WRAITER 0.20.3

Local Windows preview, 5 November 2026.

- DOCX, ODT and EPUB save directly, without a destination selector. The submit button names the file format, such as **Save ODT file…**.
- Discord, Telegram bot formats and formatted text copy directly using **Copy to clipboard**, without a destination selector or misleading file extensions in their format names.
- Plain text, Markdown, BBCode and HTML retain file/clipboard choices. PDF offers only **Save to file** and **Preview / print**, with an appropriate action button and icon.
- Automatic destinations ignore incompatible saved preferences while preserving meaningful destination choices. Remembered export settings and **Reset to defaults** continue to work.

This is an unsigned local installer build. The previous public GitHub release remains 0.20.2.
