# WRAITER 0.20.0

Local Windows preview, 2 November 2026.

- Removed the extra writer-tools toolbar. Track changes, footnotes/endnotes and paragraph layout now open from the native Tools menu alongside Spelling and grammar.
- Rebuilt review as a side panel with original/proposed wording, an added/removed legend, explicit recording status and individual or chapter/document-wide Accept/Reject. Stopping recording keeps pending edits. Review decisions remain undoable.
- Combined newly recorded replacements into one decision and fixed repeated deletion through pending removals. Proposed text retains its normal colour; underlines and strike-throughs identify the edits.
- Made note numbers clickable and added clear insert/edit/delete dialogs plus a list of the current chapter's notes. Note operations preserve surrounding prose and formatting.
- Replaced the raw tab-stop list with paragraph layout controls in centimetres/points, a preview, regular tab spacing, explicit scope and one-step undo. Only changed fields are applied; imported uneven stops survive unrelated adjustments.

Tracking still records text within one paragraph. The review panel explains when recording must be stopped for paragraph breaks, formatting, objects or other unsupported edits. Notes have plain-text bodies; PDF/EPUB collect them in a notes section. This unsigned preview has not been installed or published.
