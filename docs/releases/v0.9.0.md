# WRAITER 0.9.0 — First public release

WRAITER is a Windows writing app that brings AI assistance into your manuscript. This first public preview focuses on helping new users get connected and learn by writing.

## Download and start

- **WRAITER-0.9.0-Setup.exe** — recommended. Guided installation with Simple and Advanced options, a choice of folder, and Windows shortcuts.
- **WRAITER-0.9.0-Windows.exe** — portable application. Runs without installing WRAITER; settings and recovery still use your Windows user profile.
- **WRAITER-0.9.0-SHA256SUMS.txt** — SHA-256 checksums for both executables.

Choose an `.exe` under **Assets**, rather than GitHub's Source code archives. This release targets Windows 10/11 on x64 Intel/AMD computers. The executables are unsigned, so Windows may show an unknown-publisher or reputation warning.

On first launch, choose Codex or Claude Code, follow the account setup, and run the short writing test. You can also set up AI later. Provider accounts and usage are separate from WRAITER.

## Learn inside the app

The new tutorial opens a separate practice manuscript with its first chapter already started. Create another chapter, then use Tab to request a real AI continuation. Practise accepting a word, accepting the whole suggestion, cancelling, and asking for alternatives to selected text.

The guide sits beneath the real workspace and highlights the controls as you use them. Further lessons introduce correction, undo/redo, private notes, writing voice, references, assistant edits, history, find, views, saving and export. Pause and resume, return to your original project, or revisit it from **Help → Writing tutorial**.

AI exercises use your connected provider's allowance. Automatic background suggestions pause in the tutorial manuscript; requests happen when you ask.

## Also included

- Chapters, multiple project tabs, recent documents and startup recovery.
- Rich text, themes, focus mode, divided-page view and customisable shortcuts.
- Previewed inline suggestions and alternatives; undoable assistant editing batches.
- Codex and Claude Code account connections, local models, Ollama and API connections.
- Persistent undo/redo, recovery saves, preceding-save backups and optional Git checkpoints.
- WRAITER, ODT, DOCX, text, Markdown and HTML editing; PDF, EPUB, office and chat-format exports.
- A beginner-oriented README, detailed user guide, troubleshooting, contributor guidance and MIT license.

## Validation and known limitations

The source suite passed 168 checks. The setup and tutorial suites passed against the packaged application. A live Codex smoke test generated and accepted a continuation and selected-word alternatives in the real practice manuscript. See [the validation report](https://github.com/LEC1224/WRAITER/blob/v0.9.0/TEST-REPORT.md) for the full scope.

This remains an early preview. A complete install/sign-in on a fresh PC and live Claude Code inference still need wider validation. Complex Word/LibreOffice features may be simplified or omitted; review compatibility notices and keep originals. macOS, Linux and Windows on ARM builds are not provided.
