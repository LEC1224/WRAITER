# WRAITER 0.14.3 — Toolbar formatting and highlight colours

This local Windows build adds common formatting controls to the toolbar. It includes the Windows file-opening and installer association fixes from 0.14.2. It has not been published as a GitHub release.

## Changes

- **Clear formatting** is directly beside the highlighter. It removes selected inline styling and resets selected paragraphs to Normal while preserving their words. Undo restores the styling.
- The highlighter has eight preset colours, a custom colour picker and **No highlight**. Removing a highlight preserves bold, underline and other formatting, and also removes imported text backgrounds.
- Highlight and imported text backgrounds blend at 26% opacity with the editor page in all three themes. Text remains fully opaque. The original colours remain in saved documents and publication exports.
- The palette supports keyboard navigation and Escape, and stays inside the minimum window size.

- `WRAITER-0.14.3-Windows.exe` — portable application.
