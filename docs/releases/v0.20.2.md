## Export settings, PDF and printing

- Export remembers the format, destination, manuscript/chapter/selection scope, title and heading choices, contents option, Office comments/revision choices, PDF colour and custom-page settings. Changes survive closing the popup, completing an export and restarting WRAITER.
- Added **Reset to defaults** inside the export popup. Reset is remembered for the next export too. A storage error is reported without preventing export.
- Remembered chapter choices are tied to their manuscript. A removed chapter or another manuscript falls back to the current chapter; selected-text scope falls back to the whole manuscript when nothing is selected.
- **File → Print** always opens PDF preview, even if the last export used another format or destination.
- Added saved manuscript page setup: A4, A5 or Letter, portrait/landscape, margins, and plain headers/footers with **{page}** and **{pages}** fields. Standard PDF, DOCX and ODT exports use it.
- Added a visible PDF print preview; temporary preview files are removed when closed.
- PDF, DOCX and ODT can include a generated contents list from chapter titles and headings, rebuilt for the exported scope.
- DOCX/ODT exports can explicitly include attached passage comments, including resolved comments, and tracked revisions. Normal publication exports use the accepted reading. Footnotes/endnotes are collected in a notes section for PDF/EPUB.

## Track changes and review

- Added text-change recording for typing, deletion and plain-text paste within a paragraph. Newly recorded replacements share one review decision, and repeated Backspace advances through visible text past pending removals.
- Added a review side panel with original/proposed wording, an added/removed legend, explicit recording status and individual Accept/Reject actions.
- Review the current chapter or whole manuscript. Bulk Accept/Reject asks for confirmation and remains one undoable action.
- Stopping recording preserves pending edits. Recording starts off when switching documents; the native menu and status indicator reflect its state.
- Unsupported structural, formatting, object and composition edits give guidance while recording, protecting pending revisions.
- Basic insertion/deletion revisions round-trip through DOCX and ODT. Both sides of a replacement survive Office saveback, although an Office file may reopen them as separate insertion/deletion records.

## Footnotes, endnotes and comments

- Added numbered footnote/endnote markers with direct click-to-edit, insert/edit/delete dialogs and a current-chapter notes list.
- Note operations preserve surrounding prose and formatting, support undo/recovery and save in native documents. Plain-text note bodies import/export through DOCX and ODT.
- Added Office passage-comment interchange and explicit export sharing, with comment-anchor protections during edits and corrections.
- Private comments no longer make an attached Office document appear changed solely because private metadata changed. Imported shared comments remain part of Office save detection; existing sidecars migrate without hiding actual edits.

## Formatting and page layout

- Added named paragraph and character styles: create/edit definitions, update linked passages, retain direct overrides, undo changes and round-trip supported style data through DOCX/ODT and templates.
- Added paragraph layout with labelled centimetre/point controls for indents and spacing, line spacing, regular tab spacing, an illustrative preview and explicit application scope. Only changed fields apply across mixed formatting. Small windows keep Apply/Cancel available.
- Added tab-stop/ruler controls and tab insertion without conflicting with AI's Tab shortcut. Imported uneven tab stops survive unrelated edits.
- Added superscript/subscript and Unicode-aware Uppercase, Lowercase, Title Case and Sentence case while preserving rich-text marks.
- Expanded Copy/Paste formatting to include before/after spacing, left/right/hanging indents, tabs and superscript/subscript.
- Added visible formatting marks, optional smart punctuation and local text substitutions. Substitutions are literal, case-sensitive and triggered by a typed space; pasted text is left alone. Changes remain undoable.
- Added table row/column operations, header controls, merge/split, cell alignment, backgrounds/borders and table removal.
- Added inline, left-wrap and right-wrap image flow, with compatibility warnings when Office export must flatten unsupported presentation.
- Moved writer-tool commands into the native **Tools** menu and removed the extra writer-tools toolbar. Spelling and grammar commands are grouped together.

## Navigation, search and local writing tools

- Added heading navigation and private bookmarks that follow their text.
- Added document templates that create independent projects without copying private anchor metadata.
- Added **Divide to new chapter here** to the editor's right-click menu. It splits at the caret, retains rich formatting/comments and opens the new chapter. A nearby heading supplies the title; its duplicate body heading is removed unless a comment requires keeping it. One persistent undo/redo restores chapter and caret state, including after restart.
- Added bounded regular-expression search and capture replacements using RE2JS, with replacement previews and undo.
- Added an offline English WordNet thesaurus and support for compatible installed LibreOffice German/Swedish thesaurus files.
- Added independent, optional local English grammar checks for repeated words, a/an and auxiliary forms such as “could of”. These work without AI.

## Optional AI grammar hints

- Added **AI grammar hints while typing**, off by default. With AI enabled, the proofreading connection checks the current plain paragraph after a three-second pause, up to 4,000 characters.
- Requests exclude titles, private notes/comments, references, conversations and writing-voice guidance. Checks skip protected notes/code/pending revisions and the practice walkthrough.
- Purple underlines offer explicit Apply/Ignore, undo, stale-result rejection and protection for unchanged formatting/comment anchors. Background checks yield to manual AI work, cancel only their own requests and back off after failures.
- Hover over an underline to see its issue type, explanation and proposed wording. Deletions are labelled. Moving away or pressing Esc dismisses the explanation without changing selection or keyboard focus.
- Right-click an underline, or use **Shift+F10**, for a cached correction alongside dictionary suggestions. Choose a replacement/deletion directly or **Explain suggestion…** for review; long edits open the review UI.
- Quick corrections respect Track changes. Undo restores the selected wording and its cached hint without another request. Editing invalidates stale menu actions; spelling, clipboard, formatting, comments and chapter commands retain their own routing.

## AI continuations and connections

- Added prose-output cleanup for continuations: reject task acknowledgements, status/analysis text, role/protocol/thinking wrappers and repeated prompt/context echoes. Quote-aware handling preserves legitimate fictional dialogue, and bounded retries avoid inserting rejected output.
- Added local/Ollama context budgeting that reserves instructions, output tokens and a margin, honours advertised context limits, preserves nearby scene text and writing voice, and reduces earlier text/references/history when needed. A notice explains reduced context; a smaller retry handles context-window errors, with actionable failure if the required prompt cannot fit.
- Capability fallback is cached for genuinely unsupported structured-output features; malformed answers do not permanently disable them. Structured retries use a lower temperature. Raw continuation prompts and protocol stop rules reduce instruction echoes without using ordinary fictional phrases as stop tokens.
- Added saved model visibility choices per connection. Hidden list entries do not invalidate existing assignments or manually entered model names.
- Updated missing-helper guidance to point to **Help → Set up AI**, including the Store's official-guide installation route.

## Diagnostics, privacy and reliability

- Added local diagnostic logs for settings, panels/dialogs/windows, explicit document/connection operations, timings, errors and renderer/main-process crash summaries.
- Logs exclude typing, manuscript/chat contents, document paths/titles, credentials, free-text settings and raw error messages. **Settings → Logging** opens the folder and controls cleanup: one calendar month by default, configurable to 1–24 months or disabled. Cleanup runs at startup, hourly and when policy changes, with bounded log rotation.
- Added **Help → Privacy and AI data** with the bundled policy and public policy URL, plus **Help → Report an AI concern** with user-controlled email/public issue forms. Reports do not automatically attach writing. Added a matching GitHub AI-content issue template.
- Extended native document/schema and persistent undo compatibility for styles, notes, bookmarks, comments and revisions. Untrusted HTML cannot forge private anchors or tracked revisions; Office import/export validates supported metadata and note text.
- Updated the user guide, troubleshooting, contributing instructions and third-party notices, including WordNet licensing and the RE2JS dependency.

## Windows installers and Microsoft Store packaging

- Fixed the installer's final Launch action to use the installed executable directly, including installations without a Start-menu shortcut. Added installer launch-probe coverage.
- Added a Windows release pipeline that requires a trusted signing identity, timestamps signatures and verifies runtime PE signatures. Unsigned preview packaging is an explicit separate command/output; this release uses that preview route because no signing identity is configured.
- Added separate x64 MSIX packaging with the reserved **LEC1224.WRAITER** identity, branded logos, manifest validation and **0.20.2 → 1.20.2.0** version mapping.
- The MSIX verifier checks archive CRCs, exact identity/version, required files, runtime Store metadata, bundled privacy/reporting text and logo dimensions, and rejects NSIS installer/uninstaller state.
- Store runtime setup opens official provider installation guides. Writing, ordinary saving, recovery and export remain available with AI off and Git absent. Distribution mode is package metadata and cannot be changed through preferences.
- Added Store submission documentation, listing text, reviewer instructions and real-app screenshots using synthetic prose. The new MSIX is prepared; Microsoft Store upload/certification remains separate from this GitHub release.

## Validation and current limits

- Production build and **445/445 unit tests** passed. Import/export regression passed **38 checks**, with **28 imported projects** passing native validation.
- Export persistence/reset workflows passed against source, the final packaged Windows app and the exact Store runtime, including restarts, PDF/Office options, unavailable selections/chapters, corrupt preferences, Print and the minimum window size.
- Clipboard/file exports and the general editing/history/PDF/EPUB workflow passed. The exact Store runtime also passed AI-off save/recovery, onboarding and second-process file-open workflows. Earlier 0.20.2 packaged AI-grammar/context-menu checks and the preceding writer-tool suites are recorded in the [validation report](https://github.com/LEC1224/WRAITER/blob/v0.20.2/TEST-REPORT.md).

- Tracking covers text within a paragraph. Notes have plain-text bodies. Contents lists have no page numbers/live Office field. Page setup uses one layout with plain headers/footers. Uneven tabs are approximated in the editor/PDF; some Office image wrapping and custom table presentation flatten with warnings. Preserve originals when working with complex Office documents.
- Release targets are Windows x64 only. macOS, Linux and Windows on ARM packages are not supplied.
