# WRAITER 0.13.0 — Editorial assistant and smoother large manuscripts

WRAITER 0.13.0 expands the assistant's editing tools, adds saved before-and-after reports with reversible changes, and improves responsiveness on large manuscripts. This changelog covers all improvements since the last public release, **0.11.0**; there was no separate public 0.12.0 release.

## Download and start

- **WRAITER-0.13.0-Setup.exe** — recommended. Guided per-user installation with a choice of folder and Windows shortcuts.
- **WRAITER-0.13.0-Windows.exe** — portable application. Settings and recovery data still use your Windows user profile.
- **WRAITER-0.13.0-SHA256SUMS.txt** — SHA-256 checksums for both executables.

Choose an executable under **Assets**, rather than GitHub's source archives. These builds target Windows 10/11 on x64 Intel/AMD computers and remain unsigned previews.

## Improvements since 0.11.0

- **Richer manuscript editing.** Ask the assistant to revise passages, apply character and paragraph formatting, convert supported BBCode to native formatting, and edit structured document blocks.
- **Chapter organization.** The assistant can create, rename, split, merge, move, and remove chapters, move document blocks, and change document settings within the requested scope.
- **Saved change reports.** Inspect the actual before-and-after text, formatting, and chapter changes from a completed editing request. Reports remain available in saved conversations after restarting.
- **Reversible assistant edits.** Each applied batch is one persistent undo step. Revert a specific batch while preserving later edits to unrelated content; conflicting changes are rejected rather than overwritten. A revert can itself be undone.
- **More context when needed.** The assistant can read additional sections of enabled references and earlier conversation messages during a task.
- **Smoother work on large manuscripts.** Incremental word counting and history fingerprints reduce repeated whole-document processing. Continuous view skips rendering distant blocks, toolbar updates are batched, pagination waits briefly while typing, and returning to recently used project tabs reuses cached document state.
- **History compatibility.** Existing history fingerprints remain supported, with a tested transition to the new format on subsequent edits.
- **Refreshed application icon and documentation.** Updated app artwork and user guidance cover editorial requests, reports, and reverting changes.

## Validation

The release passed **195 automated tests** and a fresh production build. Packaged-app workflow results and SHA-256 hashes are recorded in the [validation report](https://github.com/LEC1224/WRAITER/blob/v0.13.0/TEST-REPORT.md).

AI workflow tests use synthetic manuscripts and local scripted providers. Live-provider editorial judgment and a complete fresh-PC installation have not been evaluated for this release.
