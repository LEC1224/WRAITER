# WRAITER 0.14.0 — Revision history and version tree

This version makes everyday undo and redo feel more like a text editor and adds a navigable history of manuscript versions. The installer is built locally; this document does not indicate a published GitHub release.

## Changes

- Typing and deletion undo in word-sized groups. Pauses, punctuation, caret moves, and other edits split groups. The underlying edit journal still records individual transactions for recovery.
- Meaningful changes create automatic checkpoints after roughly 40 changed words or a structural or metadata change. Manual versions remain available at any time.
- The Checkpoints panel shows a searchable version tree. Preview a saved chapter, continue from an older checkpoint, and return to either branch later.
- Choose a separate **Version summaries** model under **Settings → Connections**. It receives bounded excerpts of changed text and writes a short label and summary. Factual labels remain available if the AI connection is offline or interrupted; foreground writing requests take priority.

## Local downloads

- `WRAITER-0.14.0-Setup.exe` — guided Windows installer.
- `WRAITER-0.14.0-Windows.exe` — portable application.
- `WRAITER-0.14.0-SHA256SUMS.txt` — checksums for both executables.

These are Windows x64 builds and are unsigned. Settings, recovery, and local history remain in WRAITER's per-user application-data folder.
