# WRAITER 0.15.0 — Manuscript revision tools

This local Windows build adds search across chapters, passage comments and reusable formatting. It includes the toolbar highlights and Windows file-association fixes from 0.14.3. It has not been published as a GitHub release.

## Changes

- **Find and replace** searches the whole manuscript or current chapter, with Match case and Whole words options. Results are grouped by chapter and jump to the selected passage.
- **Preview replace all** shows every proposed replacement before applying it. The complete batch is one persistent undo step, including replacements across chapters. A changed manuscript requires a fresh preview.
- **Comments** attach private revision notes to selected passages. Edit, resolve, reopen or delete them, and filter by Open, Resolved or All. A removed passage leaves a saved detached note; undo restores the anchor.
- Comments travel in `.wraiter` files and stay in local companion state when editing other file formats. Comment bodies stay out of AI context, and exports and rich clipboard output omit comment bodies and anchor identifiers. Imported Office comments retain their existing Project notes behaviour.
- **Copy formatting** and **Paste formatting** are on the toolbar. Copy uses the start of the selection; paste applies to selected text and touched paragraphs, or the current paragraph at a cursor. It preserves target words, links, comments, lists, tables and manual page breaks. The formatting can be reused during the app session, and each paste is one undo step.
