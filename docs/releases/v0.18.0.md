# WRAITER 0.18.0

Local Windows preview, 2 November 2026.

- Added local diagnostic logging for settings, panels, windows, document operations and errors, with one-month automatic cleanup configurable under Settings → Logging. Typing and private writing are excluded.

- Added classic writer tools: named styles, paragraph controls and tab stops, notes, tracked text review, Office comments/revisions, templates, bookmarks, richer table controls, image wrapping and offline English thesaurus lookup.
- Added saved page setup, headers/footers and page fields, PDF print preview, generated export contents lists, formatting marks, optional smart punctuation, substitutions and RE2 search replacements.
- Added optional inline AI grammar hints with explicit Apply/Ignore, undo, stale-response protection and background request priority. The setting is off by default and uses the selected proofreading connection.
- Grouped spelling and grammar controls under Tools → Spelling and grammar.
- Fixed note insertion over selected prose, old history compatibility, Office comment privacy/save detection, and formatting preservation during AI grammar corrections.

See the user guide and test report for format fidelity limits. This local build is unsigned; it is not a new public GitHub release.
