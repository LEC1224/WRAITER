# WRAITER 0.21.0 RC 1 — Cloud beta

The first browser version shares WRAITER's editor and document formats with the
desktop application. It is hosted at https://wraiter.lecani.se, with a
private database operated by the publisher.

- Email registration and confirmation from `noreply@lecani.se`, password
  reset and sign-out. Passwords require at least ten characters including a
  letter and a number; uppercase letters and symbols are optional. Passwords are
  stored as independently salted scrypt hashes, with secure browser sessions.
- Private manuscript library, browser import/download, autosave, persistent
  editing history, up to twenty checkpoints and browser recovery drafts. Stale
  cloud saves are rejected rather than overwriting another device's changes.
- Each account has 1 GB of storage for its document content, images, history,
  conversations, checkpoints, references and settings. The existing 60 MB
  document limit remains; document plus cloud history is limited to 64 MB.
- The browser supports user-supplied cloud API connections for OpenAI,
  Anthropic, xAI, OpenRouter and Google. API keys remain in browser memory and
  are sent transiently through the server to the chosen provider. The web app
  cannot launch local models or account helpers and has no publisher AI key.
- Smaller screens use compact menus. A keyboard-adjacent writing toolbar gives
  AI Tab, bold, italic, text-size and undo/redo controls without moving the
  manuscript selection. The same web editing features remain reachable.
- The desktop app's Cloud library connects to the same account. Uploads and
  updates are explicit; opening a cloud document creates a separate local copy.
  Desktop transfers preserve manuscript contents, references, chats and embedded
  checkpoints, while starting a fresh cloud undo history. Local history stays
  intact. Cloud revision conflicts preserve the existing cloud version.
- A scheduled SSH backup keeps a verified database copy and the server configuration on a separate machine.

The cloud beta does not synchronize desktop files automatically or provide live
collaboration. Browser PDF export uses the browser's print/save-as-PDF dialog.
The browser has its shared spelling/grammar rules; the desktop's bundled Java and
native neural grammar engines remain desktop features.

Validation includes backend authentication, ownership, quota, revision conflicts,
password reset, backups, desktop credentials, browser registration/editor saves,
recovery and mobile writing controls. Provider responses in automated tests are
synthetic; no paid generation or publisher Codex allowance is used by the tests.

Operational paths, startup, certificates, backup scheduling and restoration are
documented in `docs/WRAITER-CLOUD-OPERATIONS.md`.
