# WRAITER 0.19.0

Local Windows preview, 2 November 2026.

- Added persistent local logs for settings changes, panel/dialog/window activity, explicit document and connection operations, diagnostic errors and process-crash summaries.
- Added Settings → Logging with Open log folder, automatic cleanup enabled by default after one calendar month, and retention adjustable to 1–24 months or disabled.
- Cleanup runs at startup, hourly and when its saved settings change. Typing, manuscript contents, chats, document paths, credentials and free-text setting values are excluded from logs.

This unsigned local build includes the existing 0.18.0 writing tools. It has not been published as a public release.
