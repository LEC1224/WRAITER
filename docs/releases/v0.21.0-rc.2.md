# WRAITER 0.21.0 RC 2 — Cloud beta

The web sign-in, library and account screens now follow the desktop app's visual
design: the original W-and-pen icon, neutral panels, blue accents, Segoe UI
controls and shared light, dark and high-contrast theme colors. The privacy page
and mobile layouts use the same branding.

Resizing the browser from desktop to mobile and back restores the manuscript
sidebar and selected side panel. Panels deliberately closed on desktop stay
closed. Mobile drawers and expanded formatting controls remain compact when
returning to the smaller layout.

Password reset now also invalidates a login or account-deletion password check
already in progress. A request using the old password cannot create a new session
or delete the account after that reset.

This release continues with WRAITER's own email accounts. OpenAI account sign-in
is deferred. The web app uses each writer's own cloud-provider API key, and
documents remain on the publisher's server with a 1 GB quota per account.

The desktop Cloud library, mobile AI Tab bar, confirmation emails, storage and
backups are described in the RC 1 release notes. The privacy policy now also
describes optional desktop cloud uploads and browser storage.

Validation covers password-reset concurrency, account and document isolation,
quota and conflict protection, browser signup and editing, desktop/mobile resize
cycles, keyboard controls, theme appearance and the packaged desktop app.
