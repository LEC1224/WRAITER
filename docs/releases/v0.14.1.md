# WRAITER 0.14.1 — Version tree and undo viewport

This local Windows build refines the revision history added in 0.14.0. It has not been published as a GitHub release.

## Changes

- Undo and redo keep the windowed writing viewport steady and reveal the restored cursor only when needed.
- The Checkpoints sidebar shows only the current path, with the newest version at the top.
- **Open complete tree** displays all checkpoints and branches as a connected graph. You can search, preview, or continue from any saved version there.

## Local downloads

- `WRAITER-0.14.1-Setup.exe` — guided Windows installer.
- `WRAITER-0.14.1-Windows.exe` — portable application.
- `WRAITER-0.14.1-SHA256SUMS.txt` — checksums for both executables.

These are Windows x64 builds and are unsigned. Settings, recovery, and local history remain in WRAITER's per-user application-data folder.
