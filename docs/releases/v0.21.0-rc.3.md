# WRAITER 0.21.0-rc.3 — cloud beta

The web and desktop Cloud libraries now encrypt document titles and full documents on the user's device before upload. A separate document passphrase and recovery key unlock the library. Account password resets cannot recover the document key. Existing beta documents migrate when their owner unlocks the library; earlier plaintext remnants need separate server maintenance.

Download library creates one ZIP containing portable `.wraiter` documents, separate editing histories and a manifest. Native save support streams the archive to disk where available; other browsers download it after creation. Downloaded files are decrypted and must be stored privately.

Browser AI goes directly to the user's configured cloud provider with the user's API key. Selected words for English thesaurus lookup stay on the device. The manuscript host has no AI proxy and cannot use the publisher's Codex subscription. Desktop Codex connections remain available through the user's local helper.

The browser uses the desktop application's icon, colors, typography and themes. Desktop panels restore correctly after a narrow-window transition. Mobile writing has a compact keyboard toolbar with AI suggestion, formatting and editing controls. Sign-in and library screens use functional labels without promotional copy.

Validation includes real-backend encrypted browser flows, desktop vault interoperability, opaque-storage checks, recovery and migration, ZIP extraction, mobile resize and keyboard controls, direct-provider request tests, and isolated packaged desktop verification. This beta installer is unsigned.
