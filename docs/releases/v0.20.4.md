# WRAITER 0.20.4

Local Windows preview, 6 November 2026.

AI grammar now checks existing and pasted text throughout the current manuscript automatically, including unopened chapters. The current chapter takes priority. Edits are queued after about half a second, and bounded batches cover multiple paragraphs at once.

Underlines remain available while other passages are checked. Edits elsewhere move a hint with its original words; changes to its grammatical sentence invalidate that hint. Replies that arrive while you type can still mark unchanged sentences. Progress appears above the manuscript. Existing hover, right-click correction, explanations, Ignore and Undo remain available.

The opt-in setting explicitly explains that this is AI-heavy and can consume substantial cloud allowance or incur charges. It also explains local-model resource use and which text is sent. Unchanged results are reused, and manual AI actions take priority.

Local grammar uses more conservative rules: valid “had had”, “that that”, auxiliary and emphatic repetitions are left alone. Article rules avoid guessing about names, abbreviations and uncertain pronunciation. “Could of course” is no longer mistaken for “could have”. Pending tracked revisions do not create phantom local errors.

The 10 November Windows preview also expands the offline checker. It catches more English agreement, tense, and word-choice errors; offers ranked spelling corrections for US, UK, Australian, and Canadian English; and adds a smaller set of Swedish grammar checks. Additional languages get bundled spelling dictionaries. These checks run locally with the optional AI tools disabled. See [offline spelling and grammar](../OFFLINE-GRAMMAR.md) for coverage and limitations.
