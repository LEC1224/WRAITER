# Reporting a security problem

Please avoid posting credentials, private manuscripts, or detailed exploitation steps in public issues.

Use [GitHub's private vulnerability reporting form](https://github.com/LEC1224/WRAITER/security/advisories/new) for this repository. Include the affected WRAITER version, the steps to reproduce the problem using synthetic data, and its potential impact. No account passwords or access tokens are needed.

Security fixes target the latest public preview. There is no guaranteed response time or separate long-term support branch yet.

For ordinary bugs, setup questions or feature suggestions, use [GitHub issues](https://github.com/LEC1224/WRAITER/issues/new/choose).
